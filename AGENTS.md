# Formatting & Chat Rules

- **NEVER use LaTeX math notation ($ or $$):**
  - The chat UI does NOT render LaTeX math syntax.
  - Never use `$O(N)$`, `$$formula$$`, `\cdot`, `\log`, `\le`, `\ge`, etc.
  - Always write mathematical expressions and Big-O notation in plain ASCII or standard markdown code ticks:
    - Use `O(N)` instead of `$O(N)$`.
    - Use `O(N * K^2)` instead of `$O(N \cdot K^2)$`.
    - Use `O(N * K * log K)` instead of `$O(N \cdot K \log K)$`.
    - Use `log2(K)` instead of `\log_2 K`.
    - Use `1000^2 = 1,000,000` instead of `$$1000^2 = ...$$`.
    - Use `<=`, `>=`, `->` instead of `\le`, `\ge`, `\to`.

# Confidentiality & Proprietary Code Safety Rules

- **STRICT PROHIBITION on Committing / Posting Proprietary or NDA Code:**
  - NEVER commit, write to public files, or expose proprietary company tasks, internal codebases (e.g., Sixit, ParkEagles, private monorepos), or confidential interview tasks protected by NDA.
  - If a task, snippet, or problem description could potentially contain proprietary, company-internal, or NDA-protected interview material, you MUST STOP and explicitly ask the user for confirmation BEFORE creating, staging, or committing it.
  - Keep all repository files focused strictly on public algorithm problems (LeetCode, NeetCode) and sanitized generic technical practice.
